TEAM Z — FULL APP DEMO (বাংলা)

এটি TEAM Z কমিউনিটি অ্যাপের একটি browser-based demo/prototype। ফাইল খুলে অ্যাপের পেজ, প্রোগ্রাম, নোটিশ, আগ্রহ জানানো এবং Admin Panel ব্যবহার করে দেখা যাবে।

কীভাবে চালাবেন:
1. ZIP ফাইল Extract করুন।
2. TEAMZ_Full_App_Demo ফোল্ডারের index.html ফাইলটি Chrome বা Firefox-এ খুলুন।
3. Admin Panel-এ ঢুকতে Login চাপুন। ডেমো লগইন:
   Email: admin@teamz.demo
   Password: teamz123
4. Admin Panel থেকে নতুন Program ও Notice যোগ/মুছতে পারবেন।
5. প্রোগ্রামে অংশগ্রহণের আগ্রহ জানাতে Login করুন।

- ডেমো admin password নিরাপদ authentication নয়; এটি কেবল prototype প্রদর্শনের জন্য।
